# SC-Project-Analysis-Code

This repository provides all necessary R code for analyzing data from the SC Project. The single file Unified analysis script.R includes:

Data reading and preprocessing
Frequentist and Bayesian modeling approaches
Model diagnostics and visualization

*How to Use*

Clone or download this repo.
Open Unified analysis script.R in R/RStudio.
Install/load the required packages (listed at the top of the script).
Run the script step by step or all at once to reproduce the analyses.

For more information regarding the output & results analysis, please refer to the internal report.
